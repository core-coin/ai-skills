# Security policy

## Reporting a vulnerability

Please use [GitHub's private vulnerability report](https://github.com/core-coin/ai-skills/security/advisories/new) when available. Include the affected skill or file, impact, reproduction steps, and a suggested fix if you have one. Do not include live private keys, seed phrases, credentials, or exploit details in a public issue.

If private reporting is unavailable, contact the repository maintainers through an established private channel before sharing details. This repository does not publish a dedicated security email address or promise a response time.

The guidance in this repository can affect financial software and infrastructure. Verify commands and configuration against the target project's current source before using them in a production environment.
